Matrix
Downloader

Aplicación de escritorio local para gestionar descargas de vídeo o audio desde URLs individuales y playlists, con selección de elementos, formatos y calidad desde una interfaz Tkinter.

Ver código fuenteInstalación y documentaciónCompilador Windows
01 / PLAYLISTS

Selección individual

Analiza una playlist y permite marcar o desmarcar los elementos que se quieren procesar.

02 / FORMATOS

Vídeo y audio

Opciones MP4, WEBM, MP3, M4A, WAV y FLAC con selección de calidad.

03 / INTERFAZ

Proceso en segundo plano

La GUI usa hilos y una cola de mensajes para mostrar progreso y logs sin bloquear la ventana.

04 / WINDOWS

Build portable

El script de compilación empaqueta la aplicación y sus componentes para generar un ejecutable portable.

FLUJO DE USO
  1. Introduce una URL de vídeo o playlist.
  2. Analiza el contenido y selecciona los elementos.
  3. Configura formato, calidad y carpeta de salida.
  4. Inicia el proceso y consulta el progreso desde la interfaz.
Showcase informativo. Esta página no realiza descargas ni aloja contenido. Utiliza la aplicación únicamente con contenido que tengas derecho a descargar y respeta las condiciones de la plataforma.
